# Poshies storefront

Poshies is an independently configurable Storefront brand. Its current route is `/poshies`.

The store currently selects the shared `storefront-foundation` and owns its accent override and scoped design tokens in `design-system/index.css`. Store-specific assets belong in `assets/` or `public/systems/storefront/poshies/`.

Poshies may adopt a fully local design system or store-specific components without changing shared commerce contracts.
