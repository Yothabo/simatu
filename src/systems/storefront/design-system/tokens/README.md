# Storefront design tokens

Shared tokens define storefront geometry, spacing, typography scale, shape, motion, responsive layout and neutral color primitives. Store-specific theme files override semantic brand roles (background, surface, text, accent, borders, hover surface, shadow color and font roles).

Shared components must consume these tokens instead of hardcoding brand values. Commerce cart, checkout, payment and order workflows are outside this design-system scope.

Initial extraction is based on the Poshies reference storefront. Tokens are being migrated incrementally; this directory is not yet a complete hardcoded-value audit.
